# Política de Privacidade — GoogleDrive-RCLONE

**Última atualização:** 19 de outubro de 2026.

## Finalidade

O GoogleDrive-RCLONE é uma integração de uso exclusivamente pessoal, utilizando o programa rclone para realizar cópias de segurança de arquivos armazenados no Google Drive.

## Acesso às informações

A integração utiliza OAuth 2.0 para acessar os arquivos autorizados pelo proprietário da conta Google.

Os arquivos são utilizados exclusivamente para operações de backup entre o Google Drive e o armazenamento local configurado pelo proprietário.

## Armazenamento e segurança

As credenciais de autenticação são armazenadas localmente na configuração do rclone. Os arquivos copiados permanecem no destino de backup definido pelo proprietário.

## Compartilhamento de dados

Esta integração não comercializa dados, não apresenta anúncios e não transfere informações para serviços de análise ou publicidade.

## Controle de acesso

O proprietário pode revogar a autorização da integração nas configurações de segurança da própria conta Google.

## Contato

O responsável pela integração é o proprietário do projeto GoogleDrive-RCLONE.
