# GoogleDrive-RCLONE Aplicativo de uso pessoal destinado à integração do Google Drive com o rclone para realização de backups automatizados. O aplicativo utiliza a autenticação OAuth 2.0 do Google para acessar os arquivos autorizados pelo proprietário da conta. **Finalidade:** copiar arquivos do Google Drive para um dispositivo de armazenamento local, mantendo uma cópia de segurança. Este aplicativo não é disponibilizado a terceiros, não possui cadastro público e não utiliza os dados para publicidade ou comercialização. [Política de Privacidade](privacy.html)
